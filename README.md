# Student Stream Selection System

A C++ console-based Student Stream Selection System that allows students to select their preferred stream, subject combination, and optional subject.

## 🚀 Features

- Science Stream
  - PCM
  - PCB
  - Optional Subjects
- Arts / Humanities
- Commerce
- Nested subject selection
- Optional subject selection
- Input validation
- Continuous menu using while loop

## 🛠️ Concepts Used

- C++ 
- `while` loop
- `switch-case`
- Nested `switch`
- `break`
- `if/else`
- User input/output

## 📚 Stream Structure

### Science
- Physics
- Chemistry
- Mathematics / Biology
- Optional Subject

### Arts / Humanities
- English
- History
- Political Science
- Geography
- Optional Subject

### Commerce
- English
- Accountancy
- Business Studies
- Economics
- Optional Subject
